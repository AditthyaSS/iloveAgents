
# Troubleshooting API Provider Errors

If you experience issues while connecting to an AI provider, follow these troubleshooting steps.

## Common Troubleshooting Steps

- **Check API Key Validity:** Ensure your API key is correct, active, and belongs to the selected provider.
- **Check Rate Limits:** Verify that you have not exceeded the provider's request or token limits.
- **Verify Model Availability:** Confirm that the selected AI model is supported and accessible with your API key.
- **Check Streaming Responses:** Ensure the provider supports streaming responses for the selected model.
- **Check Account Billing:** Verify that your provider account has sufficient credits or an active billing configuration.
- **Retry Failed Requests:** Wait briefly and retry if the provider is temporarily unavailable.

## Supported API Providers

- **OpenAI:** https://platform.openai.com/
- **Anthropic:** https://console.anthropic.com/
- **Google Gemini:** https://aistudio.google.com/
- **OpenRouter:** https://openrouter.ai/

## Security Reminder

- Never share your API keys publicly.
- Do not commit API keys to GitHub.
- Revoke exposed keys and generate new ones.
- Use only official provider dashboards to manage API keys.
