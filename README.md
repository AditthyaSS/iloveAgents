## Repository Highlights

- **Open-source and community-driven** — built by contributors.
- **Multiple AI providers** — supports OpenAI, Anthropic, Google Gemini, and other configured providers.
- **Battle Mode** — compare AI responses side by side.
- **AI Workflow Builder** — connect multiple agents into automated workflows.
- **Scheduled Automations** — schedule recurring agent runs with execution history and email alerts.
- **Privacy-focused** — browser-based API calls for standard agent runs.
- **Extensible architecture** — add new agents through configuration files.
- **Contributor-friendly** — welcoming to beginners and open-source contributors.
